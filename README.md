# NovaBits Store

A complete storefront for digital goods: browse the catalogue, pay in crypto,
and the order is delivered the moment the payment confirms.

**Live store:** https://fyosamu.github.io/novabits-store/

## What is here

| File | |
| --- | --- |
| `index.html` | Storefront - catalogue, what's included, how it works, FAQ |
| `about.html`, `contact.html` | The shop's own pages |
| `privacy.html`, `terms.html` | Real policy pages rather than placeholders |
| `style.css`, `script.js` | Theme, storefront and checkout behaviour |

The catalogue is **premium WordPress themes** for shops, login pages, blogs
and landing pages - lifetime updates, instant delivery, paid by **crypto**.

## Stack

Plain HTML, CSS and JavaScript. No framework, no build step, no backend to
patch and nothing to keep running.

Open `index.html` locally, or publish the folder to any static host - the live
version runs on GitHub Pages.
